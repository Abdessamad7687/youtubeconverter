# Third-party notices

## threads-cli

The production converter uses `threads-cli` version 0.1.1 by Tam Nguyen to
resolve media URLs from public Threads posts. The project is licensed under the
Apache License 2.0: https://github.com/tamnd/threads-cli

The helper does not authenticate to private accounts. toTube accepts only
public post URLs that can be accessed without signing in.
